# Portfolix Tech Website

A modern multi-page company website built with React and Vite for Portfolix Tech.

## Features

- Responsive Navbar
- Hero Section with Interactive Background Animation
- About Us Page
- Services Page
- Contact Page
- Google Maps Integration
- Smooth Page Animations using Motion
- Modern Black & Red Theme
- Reusable React Components

## Tech Stack

- React
- Vite
- React Router DOM
- Motion
- CSS3

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd portfolix-website
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
